How this preview works

  • One fixed WebGL canvas sits behind real HTML. Text stays crawlable and selectable.
  • Grass is one GPU-instanced draw call; it bends toward your cursor and grows with the score.
  • Negative-item tiles use simple hand-written physics. Each one you knock away ticks the illustrative score up. Keyboard users can tab to each item.
  • The repair-to-fund story is scrubbed by scroll (GSAP ScrollTrigger + Lenis) and runs backwards when you scroll up.
  • Maxine answers from a fixed knowledge base in this preview. There is no live AI behind it.
  • Theme comes from config.json: colors, logo, copy, tiles, story and Maxine's answers. Swap the file to get a different client.
  • Mobile uses fewer blades and tiles and a pixel-ratio cap. Reduced motion shows still frames. No WebGL falls back to CSS.
