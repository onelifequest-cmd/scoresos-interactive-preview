How this proof works

  • One fixed WebGL canvas sits behind real HTML, the same approach Lusion uses. Text stays crawlable and selectable.
  • The grass is one GPU-instanced draw call, with each blade bent in the vertex shader by wind and by your cursor. Its height follows the score.
  • The score ring is a shader plane lined up every frame with the HTML box around the number (DOM↔WebGL sync).
  • Theme comes from config.json: colors, logo, copy, score range and blade counts. Swap the file to get a different client.
  • Mobile uses fewer blades and a pixel-ratio cap. Reduced motion shows one still frame at the final score. No WebGL falls back to a CSS ring.
